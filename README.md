# 🎮 Rock Paper Scissors

An interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**.

Play against the computer, track the score, and see the result instantly.

## 🚀 Live Demo

🔗 **[Play Rock Paper Scissors](https://nrohanchoudhury.github.io/Rock-Paper-Scissors/)**

## ✨ Features

* 🪨 Rock, 📄 Paper, and ✂️ Scissors choices
* 🤖 Random computer moves
* 🏆 Automatic winner detection
* 📊 Real-time score tracking
* 🎨 Interactive UI with hover effects
* 🔄 Unlimited rounds

## 🛠️ Tech Stack

* **HTML5** — Structure
* **CSS3** — Styling and layout
* **JavaScript** — Game logic and DOM manipulation

## 🎯 How to Play

1. Choose **Rock**, **Paper**, or **Scissors**.
2. The computer randomly selects a move.
3. The game determines the winner.
4. The score is updated automatically.
5. Play again and try to beat the computer!

### Game Rules

| Choice      | Beats       |
| ----------- | ----------- |
| 🪨 Rock     | ✂️ Scissors |
| 📄 Paper    | 🪨 Rock     |
| ✂️ Scissors | 📄 Paper    |
